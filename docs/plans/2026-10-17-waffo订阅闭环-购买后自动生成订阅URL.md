# waffo 订阅闭环：登录→购买→自动续费→订阅 URL（替代 bind 页）

## 0. 决策记录
- 购买模型 = **自动续费订阅**（用户拍板，2026-10-17），非一次性加油包
- 支付/MoR = Waffo Pancake（官方 Go SDK `github.com/waffo-com/waffo-pancake-sdk-go`：零依赖、RSA-SHA256 签名、webhook 验签内嵌公钥、authenticated checkout、customer portal）
- 复用层 = 抽独立 package `waffo-kit`（Go module，本项目先当第一消费者，后续其他项目直接引用）——模式同 webkit 抽取先例
- 旧流程废弃：**bind 页（用户贴 token）从用户流程删除**，降级为 admin「用户管理」里的存量补绑迁移工具；token 从"门槛"变成"付款后系统生成的产物"
- 核心原则：**Waffo = 计费真相源，我方 = 幂等投影**。事件到达→查/取订阅当前周期→resync 写 Marzban，绝不做增量算术；事件非 2xx 会重试、timestamp 复用，幂等靠 eventId 去重表

## 1. 端到端流程
```
登录(acct) ─┬─ 有活跃订阅 → dashboard：流量/到期/订阅URL(Clash)/QR/「管理订阅」(Waffo portal)
            └─ 无订阅 → 套餐页(月付/年付) → POST /billing/checkout
                 → waffo-kit authenticated checkout(BuyerIdentity=acct:<id>,
                   OrderMerchantExternalID=uc_sub:<uuid>)
                 → 跳 Waffo 托管收银台(微信/卡) → 付款
                 → webhook subscription.activated → provision:
                      marzban.CreateUser(uc-<n>, token=随机32位, expires_at=本期期末,
                        data_limit=套餐流量, inbounds=MARZBAN_INBOUND_IDS)
                      写 uc_account_links + uc_subscriptions 镜像
                 → 用户回到站点，dashboard 已见订阅 URL
续费 = subscription.renewed → PUT 延期到新学期末 + 流量归零
```

## 2. Waffo 事件 → 我方动作映射表（事件目录实测自 llms-full.txt）
| 事件 | 动作 | 备注 |
|---|---|---|
| `subscription.activated` | provision：CreateUser + 绑定 + 镜像 | 首购，eventId 去重 |
| `subscription.payment_succeeded` | 仅记账 | 纯支付事件，周期以 renewed/订单为准（首购会连同 activated 双发——FAQ 已确认） |
| `subscription.renewed` | resync：PUT 延 expires_at=新期末、data_limit=套餐、used_traffic 归零 | eventId=OrderID+periodEnd，天然幂等键 |
| `subscription.recovered` | resync（同 renewed 逻辑） | 逾期后重试成功 |
| `subscription.past_due` | 不动作 | 平台次日重试一次，二败转 canceled；Marzban 按 expires_at 天然兜底 |
| `subscription.canceling` | 镜像置 canceling，不动作 | 期末前仍可用 |
| `subscription.uncanceled` | 镜像回 active，resync | |
| `subscription.plan_changed` | PUT 新套餐 limit + 期末按订阅记录 resync | |
| `subscription.plan_change_scheduled` | 记 intent，renewed 时应用 | |
| `subscription.canceled` | 镜像置 canceled，不续期 | 到期后 Marzban status=expired，只读宽限由面板兜底 |
| `refund.succeeded` | **断供**：expires_at=now + 镜像 suspended | 退款即不再提供服务（默认策略，可调） |
| `refund.failed` | 记录 + admin 告警徽章 | |

状态镜像：`uc_subscriptions(account_id, waffo_subscription_id, plan, status, period_end, current_product_id, event_cursor, updated_at)`；三角色页面数据（dashboard/管理页）全从镜像+实时 Marzban 出，webhook 断连时页面仍可读（滞后但一致）。

## 3. 边界策略
- **一账号一活跃订阅**：checkout 前查镜像；换套餐引导走 Waffo portal（plan change 归 Waffo 管 proration）。若出现第二订阅付款（绕过前端），provision 取最新、旧的标记 `orphan` 供 admin 处理
- 试用期：Waffo trial 走同一 activated 路径，期末从订阅记录取
- 退款/拒付：refund=断供；chargeback 文档流程留 admin 页人工徽章（事件目录无 chargeback 事件，走 dashboard 通知）
- 无 Waffo 凭证时：`waffo-kit` stub 模式（本地假收银台一键确认→发合成事件），开发/E2E 不阻塞
